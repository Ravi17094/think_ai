# Thinkz AI Client Demo Recording Script

## Before recording

- Use an approved demo account and safe test data.
- Close personal applications and browser tabs.
- Disable notifications.
- Do not show passwords, tokens, API URLs, or private client records.
- Record each section separately so it can be shared as a short clip.

## Clip 1 - Learner journey (2-3 minutes)

1. Introduce Thinkz AI and sign in as a learner.
2. Open a course and show the learning path.
3. Open one lesson or assessment using prepared test content.
4. Explain how the learner tracks progress.
5. End with: "The learner workflow keeps course content and assessment progress in one place."

## Clip 2 - Instructor and TA tools (2-3 minutes)

1. Sign in with the approved Instructor or TA account.
2. Open the TA dashboard and explain the course/assessment summary cards.
3. Demonstrate attendance using a safe test learner.
4. Open the attendance report and explain filtering/export only if enabled for the demo account.
5. Open Instructor Controls and show the session-preparation checklist.
6. End with: "These tools help teaching teams prepare, monitor, and follow up on a session."

## Clip 3 - Admin and RBAC (2-3 minutes)

1. Sign in as the approved Admin demo user.
2. Open **Admin > Users** and explain that Admins manage access.
3. Open **Admin > RBAC**.
4. Explain that permissions are assigned by role and changes are staged before saving.
5. Make one pre-approved test change, save it, and state that the activity can be reviewed in audit logs.
6. Open **Admin > Audit logs** and show the matching test activity.
7. End with: "Role-based access keeps permission management restricted to authorised Admin users."

## Clip 4 - Reporting and analytics (2-3 minutes)

1. Open the attendance report or approved analytics screen.
2. Explain the summary cards and status filters.
3. Demonstrate CSV export only with safe test data and client approval.
4. End with: "Reporting gives teams a clear view of attendance and learning activity."
